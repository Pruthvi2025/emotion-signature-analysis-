About Our Project

Project Overview

The Signature Emotion Analysis project utilizes Machine Learning (ML) techniques to analyze handwritten signatures and predict the emotional state of an individual. This system examines various signature characteristics, including patterns, styles, stroke pressure, slant, spacing, and speed, to extract meaningful features that correlate with emotional expressions. By leveraging classification algorithms such as Support Vector Machine (SVM) and Random Forest Classifier, the model identifies and categorizes emotions into four primary states: Happy, Sad, Angry, and Normal.
